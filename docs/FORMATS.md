# Format policy

| Format | Category | Preferred use |
|---|---|---|
| STEP/STP | BREP | neutral mechanical interchange |
| IGES/IGS | BREP/profile | legacy interchange |
| BREP | BREP | OCCT-native exchange |
| FCStd | native | FreeCAD documents |
| STL | mesh | slicer/manufacturing output |
| 3MF | mesh/package | modern slicer output |
| OBJ | mesh | broad mesh interchange |
| PLY | mesh | scan/point-color workflows |
| GLB/glTF | mesh/scene | browser/visualization |
| DXF | profile | 2D drawings/profiles |
| SVG | profile | 2D vector profiles |
| SCAD | source | OpenSCAD parametric source |
| PY | source | build123d/CadQuery/automation |
